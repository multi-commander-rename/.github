# Multi Commander - See the Folder You Are Copying Into

## Berth

The source folder is one you may change or copy from.
The destination has room and a path you can read out loud.
A third pane exists only if the job has a third place.
Explorer can still open each of those paths, so you can check the result without this program.

## Tide

Two panes are the whole trick. More panes help only when you can still point at the destination without guessing.
A filter that hides extensions will make two different files look like one. Turn the filter off while you copy.
A network drive that sleeps will hang a pane. Wake it or close the pane.
USB letters change. The pane that still says the old letter is wrong. Point it again before you drag.

## Line

Put the source on one side and the destination on the other.
Copy one small file.
Open it in the destination.
Only then copy the set, still watching the target path.

## Fender

A dummy delete should appear in the recycle bin before you trust delete on a real folder.
A rename is one name, then you look.
A zip is not a folder until an archiver says so. Dragging it may only copy the zip.
A search box in the manager finds names in the open folders. It is not a search of every document on the PC.

## Current

The destination holds the test file and it opens.
The source still has it if you copied.
A move emptied the source only because you chose move.
Explorer shows the same thing.

## Do not sail

Do not use a system directory as a scratch pane.
Do not tidy someone else's profile.
Do not run an installer from a preview because you were curious.
Do not leave a job copying onto the only backup disk without looking.
Do not set this as the shell for Windows until you have used it for a week and still want that.

## Return

Close the extra panes.
Clear a filter you turned on for one search.
The copy you care about is in a normal folder.
The program can exit. The files do not need it running.

## Chart

Source path.
Destination path.
Copy or move.
Whether the bin was tested.

## Not this harbor

A sync tool repeats a pair of folders while you are away. This copies when you press the button.
A compare tool shows line differences. This shows files.
An image mounter gives you a drive letter for an ISO. This does not.
A cleaner does not belong in the same hour as a large move.
Four panes do not make four backups.

## Next tide

## Log

You can say which pane was the target.

## Harbor master

A shared PC gets this closed before the next person logs on.
A portable copy, if you use one, is the program, not your documents. Do not mix them in one zip you hand around.
Uninstall leaves every file you copied.
A wrong move comes back from the other pane or the bin, not from reinstalling the manager.
